# Proyecto A: Pixel-Quest (Motor RPG & Exploración de Mazmorras)

Este proyecto implementa un motor de videojuego RPG en consola utilizando Arquitectura en Capas adaptada a POO y desarrollado mediante co-pilotaje asistido por IA.

## Integrantes y Roles
- **GitMaster / CLI UI:** Integrante 5 (GitMaster)
- **Dominio Core:** Integrante 1
- **Dominio Reglas & Excepciones:** Integrante 2
- **Servicios & Combate:** Integrante 3
- **Servicios & Persistencia JSON:** Integrante 4

## Estructura de Capas
- `src/domain/`: Modelos de objetos y excepciones de negocio.
- `src/services/`: Lógica de juego, combate y persistencia de datos.
- `src/ui/`: Interfaz de consola e integración principal.
